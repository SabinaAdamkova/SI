KOČIČÍ ZAHRADA – statický web útulku
====================================

Obsah:
  index.html          stránka
  style.css           styly
  images/             logo, ikony a fotky (zatím zástupné)
  stahnout-fotky.ps1  stáhne fotky koček z Unsplash (Windows)
  stahnout-fotky.sh   totéž pro Mac/Linux

1) FOTKY
   Spusťte stahnout-fotky.ps1 (nebo .sh). Nahradí zástupné obrázky
   v images/ skutečnými fotkami z Unsplash (licence Unsplash, volné
   i pro komerční použití). Fotky můžete kdykoli vyměnit za vlastní –
   stačí zachovat názvy souborů (micka.jpg, oskar.jpg …).

2) CO UPRAVIT V index.html
   - název útulku, adresu, telefon, e-mail, číslo účtu, IČO
     (všechny teď obsahují vzorové údaje)
   - jména a popisy koček, statistiky v úvodu, otevírací dobu

3) NAHRÁNÍ NA HOSTING
   Nahrajte celý obsah složky (index.html, style.css, images/) přes FTP
   nebo správce souborů hostingu do kořenové složky webu
   (obvykle www/, public_html/ nebo htdocs/). Skripty a README nahrávat
   nemusíte. Hotovo – web poběží na vaší doméně.
